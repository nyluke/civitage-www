# Civitage brand

**Colors.** Ink `#0e1217` and paper `#f4f1ec`. Use ink on light backgrounds and paper on dark ones. There is no accent color.

**Type.** [Geist](https://vercel.com/font) (SIL Open Font License). Headings in Medium, body in Regular. The wordmark is Geist SemiBold, uppercase, tracked +0.12em, and converted to outlines so it renders the same without the font installed.

**Mark.** A C made of seven square blocks on a 3×3 grid: 10-unit blocks with 3-unit gaps, with the center and middle-right blocks left out.

| File | Use |
| --- | --- |
| `logo.svg`, `logo-white.svg` | Mark and wordmark, for documents, slides, and email signatures |
| `mark.svg`, `mark-white.svg` | Mark alone, for small spaces |
| `avatar.png` | 1024×1024 profile picture for Slack, Zoom, LinkedIn, etc. |
| `zoom-background.png` | 1920×1080 virtual background |
| `og.png` | Link-preview image the site points to |
